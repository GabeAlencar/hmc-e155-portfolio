## FPGA

Board: UPduino v3.1 (Lattice iCE40 UltraPlus). Synthesized and programmed with
Lattice Radiant; simulated with QuestaSim.

## MCU

Board: Nucleo-L432KC (STM32). Developed with SEGGER Embedded Studio.
